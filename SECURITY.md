# Security

Report vulnerabilities privately through [GitHub security advisories](https://github.com/jhagmar/solace/security/advisories/new).

A vulnerability is a defect that lets someone read or change another user's data, run code in the app, or otherwise bypass a security control. Please include the affected version, a description of the issue, and steps to reproduce. Do not open a public issue for an unreleased vulnerability.

We aim to acknowledge a private report within 7 days and to disclose a fixed vulnerability within 90 days of the report, or sooner when a patch is ready.
