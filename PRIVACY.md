# Privacy

Solace runs in your browser. There is no Solace account and no Solace server.

Location search and UV forecast requests go to [Open-Meteo](https://open-meteo.com/). Skin tone, sunscreen, outdoor windows, theme, the selected place, recents, and the simulation log stay in this browser's `localStorage`.

Clearing site data for this origin deletes that state. A host of the static files may see ordinary web-server access logs for those files.
